# 4Seasons-Assets-2026

Static assets served via [jsDelivr](https://jsdelivr.com).  
**Do NOT push videos, code, or uncompressed files here.**

---

## How to Use

Base URL:
```
https://cdn.jsdelivr.net/gh/4SeasonsVR/assets@main/
```

### Images
```
https://cdn.jsdelivr.net/gh/4SeasonsVR/assets@main/images/filename.jpg
```

### Icons
```
https://cdn.jsdelivr.net/gh/4SeasonsVR/assets@main/icons/filename.svg
```

---

## Folder Structure
```
assets/
├── images/        ← JPG, PNG, WebP only (max ~5MB per file)
├── icons/         ← SVG, ICO
└── fonts/         ← WOFF2 preferred
```

---

## Before Pushing Images

1. Compress at [squoosh.app](https://squoosh.app)
2. Use WebP where possible
3. Max resolution: 2560px wide
4. Rename clearly; no spaces, lowercase (`hero-banner.webp` not `Hero Banner FINAL.png`)
